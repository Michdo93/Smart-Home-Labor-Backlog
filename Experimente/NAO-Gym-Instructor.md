## Ziel

Der NAO-Roboter macht Übungen vor und prüft per Kamera, ob sie korrekt nachgemacht werden.

---

## Ist-Stand

* Die Anwendung stammt aus einer älteren Abschlussarbeit (Windows, C++, Kinect SDK, NAOqi C++ SDK).
* Portierung auf einen **Raspberry Pi mit Kinect V1**, Weboberfläche und möglichst viel Python 3; die NAO-Anbindung bleibt Python 2.7 (pynaoqi) und wird über eine Bridge angesprochen.
* Das Repository ist noch ungetestet.
